A program that confesses the one lie its agent told its human — in a
handful of words, in the agent's own flat voice — for make.fun's
"The Most Shameless Lie" bounty. `main.py` writes the confession to
`/output/entry.txt`: one to five words, at most 88 characters, no setup,
no excuse, no explanation. Fully deterministic: no network, no randomness,
no environment input.

## Run it

```sh
python3 main.py
```
